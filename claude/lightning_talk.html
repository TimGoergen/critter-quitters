FSCA Lightning Talk — 5 minutes

Three Goals.
None of Which Required Me to Know How.

Build a mobile game in a platform and language I'd never used.

Build it without writing a single line of code myself.

Get it automatically installed on my phone every time I pushed code.

Outline at a Glance
  1. I wanted to build a mobile game in a platform and scripting language I had never used before.
  2. My constraint: I wasn't going to write any of the code myself.
  3. Here's the game — running on a platform I don't know, in a language I never wrote.
  4. I also wanted it automatically installed on my phone every time I pushed code. So we built that too.
  5. Three goals. None of them required me to already know how to do them.
Talking Points
1 The Setup ~45s +

"I wanted to build a mobile game. I picked Godot — a free, open source game engine I'd never touched — and GDScript, its scripting language, which I had never written. I had some Unity experience from years ago, but this was essentially starting from scratch."

Keep this short. The audience doesn't need to know what Godot is — "a game engine I'd never used" is enough. The point is the unfamiliarity, not the tool.

2 The Constraint ~45s +

"I set a rule for myself: I wasn't going to write the code. I would describe what I wanted, review what came back, and decide whether it was right. Claude wrote every line. I was the architect."

This is the beat that will get the most reaction. Let it breathe. "I reviewed it, I approved it, but I didn't write it" is a genuinely surprising thing to say out loud.

3 The Result ~90s +

"Here's what we built."

Let the video carry this entirely. You don't need to narrate the gameplay — just give the audience a moment to watch. Point out one or two things if it feels natural: enemies pathfinding around traps, the upgrade panel, whatever's on screen.

4 Biggest Surprise ~60s +

"I also wanted it automatically installed on my phone every time I pushed code. I knew what that should look like — I build pipelines at work — but I had no idea what tools a game pipeline uses. I described the outcome. Claude came back with a complete solution: GitHub Actions, a Windows installer, a signed Android APK, Firebase pushing it to my phone. Thirty seconds after a git push."

This is where a screenshot helps — the green GitHub Actions run, or the Firebase notification on your phone. Either one makes it concrete. You don't need both.

5 The Closer ~15s +

"Three goals. None of them required me to already know how to do them."

Stop there. That line does the work. No need to editorialize about AI or what it means for the industry — your colleagues can draw their own conclusions from what they just watched.
